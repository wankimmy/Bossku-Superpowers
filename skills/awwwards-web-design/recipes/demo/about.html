A2 · data-reveal="lines"

Reveals re-run on every page because each page boots its own motion layer

Cross-document transitions do not keep JavaScript state. Lenis, ScrollTrigger and the reveal registry start fresh on each page. A site that must keep a WebGL canvas or audio alive across pages needs a PJAX router with same-document transitions instead: see window.pageTransitions.swap() and motion-stack.md 4.11 B.

# Notice

## Data provenance

`skills/awwwards-web-design/data/` holds measurements and derived metadata about third-party websites. It was collected on 2026-09-24 and 2026-09-25 from public pages on awwwards.com and from the winning sites themselves.

- **What it contains:** jury scores, tags, palette values, element titles, fonts found in stylesheets, CSS easing values, library signatures, and teardown notes written for this project.
- **What it does not contain:** copied site content, images, videos or code beyond short identifying snippets. No screenshots or video frames are shipped.
- **Ownership:** Awwwards and every site, studio and brand named in the data belong to their respective owners. This project is not affiliated with Awwwards.
- **Removal:** if you own a site in the corpus and want its entry removed, open an issue.

## Third-party references

The research files cite their sources inline. Fonts, libraries and tools named in the guidance (for example GSAP, Lenis, three.js and the type foundries) keep their own licenses. Nothing from them is redistributed here except the MIT-licensed recipe code, which is original.

The optional companion "anti-slop design law" is published at https://pols.dev/slop.md. It is linked, not included.

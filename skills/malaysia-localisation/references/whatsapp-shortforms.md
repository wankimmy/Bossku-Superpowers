# WhatsApp shortforms

Understand abbreviations without forcing them into output. Expand mentally and
use context; “kt” can stand for kat/dekat and is not a reliable location parser.

| Input | Common reading |
|---|---|
| nk | nak |
| x / tak | tak / tidak; x may be a literal symbol elsewhere |
| dh | dah / sudah |
| jap / kejap | sekejap |
| yg | yang |
| dgn | dengan |
| brp | berapa |
| org | orang |
| sbb | sebab |
| tnya | tanya |
| sy | saya |

Prefer “Nak tanya, harga berapa?” over dense shorthand for a broad audience.
Mirror denser shorthand only when requested or clearly established and readable.
Keep amounts, account numbers, addresses, links, dates and negation legible.
“x jadi” and “jadi” have different meanings; do not drop the negative.

WhatsApp can be professional. A short customer message can read “Boleh kongsi
nombor pesanan? Saya semak dulu.” It does not need aku/kau, emojis or “lah”.
Preserve an explicit no-emoji or no-abbreviation preference. Do not interpret
short input as a request for curt or dismissive replies.

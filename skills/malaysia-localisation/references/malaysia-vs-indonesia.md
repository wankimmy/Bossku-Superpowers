# Malaysian BM and Indonesian

Use Malaysian BM defaults when a Malaysian BM register is intended. Differences
are contextual, not a word blacklist. Both languages share substantial vocabulary;
quoted Indonesian and explicit Indonesian translation must remain valid.

| In an Indonesian conversational frame | Malaysian BM default for this sense |
|---|---|
| bisa (ability) | boleh |
| nggak / gak | tak / tidak |
| udah | dah / sudah |
| gimana | macam mana / bagaimana |
| karena | sebab / kerana |
| banget (intensity) | sangat / betul-betul; colloquial choice by context |
| kantor | pejabat |
| mobil (car) | kereta |
| silakan (invitation) | sila / jemput |

Kamu, saya, anda, boleh and sudah are not proof of Indonesian. Bisa can denote
venom in Malay; do not replace that sense with boleh. Malay compound terms such
as telefon bimbit may be right in formal BM even when casual speakers say phone.
Do not turn this table into a global search-and-replace operation.

For a quoted line such as “nggak bisa”, keep the quotation when explaining it.
If the user asks for Indonesian, use Indonesian. In bilingual comparison, label
the varieties clearly. In casual Malaysian BM, “Tak boleh buat macam tu” is an
original alternative to an ability-related Indonesian sentence, not a mandatory
phrase for every negative answer. Use PRPM for doubtful standard BM usage when
lookup is available; avoid inventing certainty.

# Code-switching

Rojak and Manglish overlap in everyday use. This package uses rojak for mixed
Malay-English phrasing and Manglish for English-led colloquial Malaysian English;
these are working labels, not rigid linguistic boundaries.

Keep a coherent grammatical frame. An English noun phrase in a Malay clause, an
English domain term, or a whole clause switch can be natural. Do not replace
alternating words mechanically or aim for a fixed language ratio.

Original illustrations:

- Malay-led: “Kalau stok dah sampai, boleh arrange delivery.”
- English-led: “The stock is here already. Can arrange delivery tomorrow.”
- Clause switch: “Aku dah check. The total is still the same.”
- Unhelpful: “The stok sudah arrive lah for delivery punya arrangement lor.”

Actual register and audience outweigh this list. Use only BM when requested;
English terms can be glossed or translated for readers who need them. Proper
names and literal code remain unchanged. Borrowed words are not automatic errors.

Preserve discourse meaning: “dah” can signal completion; “belum” non-completion;
“boleh” may ask permission or ability. A fluent rewrite must not change “belum
bayar” into a paid status. Prefer a single clear clause when mixing obscures meaning.

## Sample-led casual wording

Keep familiar English vocabulary and spoken clause structure when the supplied
voice uses them. Polishing is not a reason to translate result into hasil or
compress a verb-led comparison into formal prose. These pairs illustrate one
requested casual rojak voice, not corrections to standard Malay:

| More formal phrasing | In that casual rojak voice |
|---|---|
| Banyak skills tidak semestinya memberikan hasil yang lebih baik. | Banyak skills tak semestinya dapat result yang lebih baik. |
| Saya menguji agent dengan dan tanpa pack itu. | Aku test agent yang pakai pack tu dengan yang tak pakai. |
| Punca belum diketahui. | Tak sure lagi sebab apa. |
| Penjelasan itu belum jelas. | Explanation tu tak clear lagi. |

Keep both comparison groups, the negation and the level of uncertainty. Unknown
cause can simply stay “tak sure lagi sebab apa”. If the source already offers
different test variables as a possibility, a matching rewrite is “tak sure lagi
sebab apa, possible variable berbeza masa test”. Do not add that explanation
when the source only says the cause is unknown or results vary. “Possible” is
not confirmation that the variables differed.

If the user prefers “tak clear”, keep that choice in matching casual rojak
sentences. Do not label “belum jelas” inherently Indonesian or ban it from
standard BM; this is a register preference, not a language-identification rule.

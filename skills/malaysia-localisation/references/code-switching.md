# Code-switching

Rojak and Manglish overlap in everyday use. This package uses rojak for mixed
Malay-English phrasing and Manglish for English-led colloquial Malaysian English;
these are working labels, not rigid linguistic boundaries.

Keep a coherent grammatical frame. An English noun phrase in a Malay clause, an
English domain term, or a whole clause switch can be natural. Do not replace
alternating words mechanically or aim for a fixed language ratio.

Original illustrations:

- Malay-led: “Kalau stok dah sampai, boleh arrange delivery.”
- English-led: “The stock is here already. Can arrange delivery tomorrow.”
- Clause switch: “Aku dah check. The total is still the same.”
- Unhelpful: “The stok sudah arrive lah for delivery punya arrangement lor.”

Actual register and audience outweigh this list. Use only BM when requested;
English terms can be glossed or translated for readers who need them. Proper
names and literal code remain unchanged. Borrowed words are not automatic errors.

Preserve discourse meaning: “dah” can signal completion; “belum” non-completion;
“boleh” may ask permission or ability. A fluent rewrite must not change “belum
bayar” into a paid status. Prefer a single clear clause when mixing obscures meaning.

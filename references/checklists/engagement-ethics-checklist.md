# Engagement Ethics Checklist

Run this on every urgency, scarcity, social-proof, default, streak, reminder, cancellation and trial element before it ships. It wins over any loaded skill that suggests otherwise, vendored ones included. Engagement serves the user's goal. Features are hypotheses until tested in the product; never claim one releases dopamine or guarantees retention.

A dark pattern steers, deceives, coerces or manipulates a person against their own interest [E1: OECD topic page]. The FTC names countdown timers on offers that are not time-limited, hard-to-cancel subscriptions, buried terms and fees, and data-sharing traps [E2: regulator press release, staff report not read]. Both are policy views, not measured results. Source ids: [playbook](../playbooks/human-centered-design-playbook.md) section 8.

## 1. Truth test: urgency, scarcity, social proof

- [ ] Real: the deadline, stock count, "people viewing" or review exists in your data today.
- [ ] No reset: a timer that restarts on reload, new visit or per user is fake.
- [ ] Verifiable: you can show the source (offer end date, inventory, real reviewers).
- [ ] Enforced: when the deadline passes, the offer ends.

## 2. Consent test: every default

- [ ] Nothing pre-ticked: no opt-in, add-on, plan or marketing consent.
- [ ] Declining is as easy as accepting: same size, place and clicks.
- [ ] No guilt wording.
- [ ] The price, renewal date and renewal price are visible before the user commits.

## 3. Streaks and reminders

- [ ] Opt-in, asked when the user can see the value.
- [ ] Flexible: a freeze, a rest day or a user-set goal [P2: one learning app, company-reported, small gain].
- [ ] A broken streak is never punished, shamed or used to pull the user back.
- [ ] Easy to pause, snooze or turn off in one place; frequency cap and quiet hours.

## 4. Cancellation and exit

- [ ] Cancelling is as easy to find and finish as signing up, in the same channel.
- [ ] A save offer is one skippable screen with real terms.
- [ ] No forced call, chat, survey or hidden link.
- [ ] Trial rules and the first charge are stated before sign-up.

## 5. Tactics to refuse

| Tactic | Why |
| --- | --- |
| Countdown that resets or has no real end | False deadline [E2] |
| "Only 2 left" with no stock behind it | Fabricated scarcity |
| Invented testimonials, counts or "viewing now" | Fabricated social proof |
| Pre-selected paid plan or add-on | Consent not given |
| Confirmshaming copy | Guilt as pressure |
| Hidden cancellation, or more steps than signing up | Obstruction [E2] |
| Punitive streak loss, guilt notifications | Pressure to return |
| Pre-completed progress the user did not do | Fake progress |

## 6. Where the law matters

Marketing messages and notifications need their own consent and an easy opt-out. Malaysian legal specifics need verification with counsel: see `bosskuai-malaysia-pdpa-privacy`.
